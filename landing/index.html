Cursor Auto Runner

A free, cross-platform system-tray app that automatically clicks the Run, Always Run and Allow / Approve buttons in the Cursor IDE — and keeps track of how often it did.

v1.2.17 Windows · macOS · Linux MIT License Electron 33

Download

🪟 Windows

Installer for x64 and ARM64. Install over an older version — your stats and templates are kept.

Download Installer (.exe) Chocolatey

choco install cursor-auto-runner

🐧 Linux

AppImage (run anywhere, chmod +x), APT for Debian/Ubuntu, direct .deb download, or .pacman for Arch.

Download AppImage APT repository Download .deb Download .pacman

sudo apt-get install cursor-auto-runner after adding the repo

🍎 macOS

Universal DMG (x64 + ARM64). Grants Screen Recording & Accessibility on first use.

Download DMG Homebrew

brew install --cask KurtStevenK/tap/cursor-auto-runner

Built via CI on tagged releases — DMGs can only be produced on macOS.

Features

🎯 Auto Run & Auto Always RunClicks Run whenever it appears; Always-Run mode also approves permission prompts so your agent never stalls.
🛡️ Approve / Allow buttonsTool-call approvals are clicked too — at any position, in both modes.
📊 Live statisticsSession, day, week, month and total clicks plus a 7-day chart in a frameless overlay (SQLite-backed).
⚡ Adjustable refresh intervalSet how often the screen is checked — from the tray menu or the stats window; applied live.
🖥️ Multi-monitor & multi-themeFinds Cursor windows on any display, dark and light themes, per-display DPI scaling absorbed.
🖱️ Cursor-safe clickingThe mouse pointer is restored after every click; cooldown and match verification prevent double clicks.

Getting started

  1. Install and start the app — it lives in your system tray (left click opens the stats).
  2. Right-click the tray icon → Capture templates… → pick the button and theme, drag a rectangle around Cursor's Run button.
  3. Choose Start Auto Run or Start Auto Always Run. Done.
